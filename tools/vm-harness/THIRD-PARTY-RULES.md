# Third-Party Detection Rules

ShadowStrike Phantom ships YARA rules aggregated from independent
research repositories. Each retains its own licence and the attribution
below is a condition of redistributing it - the Detection Rule License
and CC BY-SA both require credit.

This file is generated by `phantom-sigbuild` from the rule package
itself. Do not edit it by hand; rebuild the signature database instead.

## Copyleft sources

Some included rule sets are under the GNU General Public License.
ShadowStrike Phantom is itself AGPL-3.0, so this is compatible and
requires no separate action. It would be a problem only for a
proprietary redistribution of these rules, which this project does
not perform.
